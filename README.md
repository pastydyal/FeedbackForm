# Feedback Form

React-приложение с формой обратной связи.

## Возможности

- Ввод контактных и паспортных данных.
- Выбор одной или нескольких услуг.
- Проверка обязательных полей.
- Валидация номера телефона.
- Согласие на обработку персональных данных.
- Уведомление об успешной отправке формы.
- Очистка полей после отправки.

## Запуск проекта

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Запустить приложение:

   ```bash
   npm run dev
   ```

3. Открыть адрес, указанный в терминале.
